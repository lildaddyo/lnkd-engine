# data/ (git-ignored)

Put private inputs here. Nothing in this folder except this README is committed.

- `LinkedInExport.zip` (or the unzipped folder): your LinkedIn "Get a copy of your data" archive.
- `Connections.csv` (optional but strongly recommended): gives company + position for every 1st-degree connection.
- `crm_warm.csv` (optional): `name,company,role,tier,vertical,linkedin_url`: VR Express CRM past buyers / dormant clients.
- `engine.db`: the engine's SQLite state (created by `python -m engine import`).
